# BUPPO Pocket PvE

Protótipo Godot 4 em retrato para testar a mecânica PvE do BUPPO como jogo nativo.

## Como abrir

1. Instale o Godot 4.x.
2. Abra o Godot.
3. Clique em **Import**.
4. Selecione esta pasta: `godot-buppo-pve`.
5. Abra o projeto e rode a cena principal.

## Estado do protótipo

- Apenas PvE.
- Sem login, PvP, loja, mochila, cosméticos ou Firebase.
- UI vertical para celular.
- Artes 2D placeholder feitas por código.
- Mecânica central portada: deck, mão, vida, nível, XP, ações, desarme, maestrias, IA e fim de partida.
